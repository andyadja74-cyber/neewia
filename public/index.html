❓ AideComment connecter mon bot ?

Suis ces 5 étapes dans WhatsApp, pas à pas. Touche une image pour l’agrandir.

1Ouvre WhatsApp et touche les 3 points

Sur l’écran d’accueil de WhatsApp, touche les 3 petits points ⋮ tout en haut à droite (là où pointe la flèche).

2Choisis « Appareils connectés »

Dans le menu qui s’ouvre, touche Appareils connectés.

3Touche « Connecter un appareil »

Tout en bas de l’écran, appuie sur le gros bouton vert Connecter un appareil. WhatsApp peut te demander ton code ou ton empreinte pour confirmer.

4Choisis la connexion par numéro

Un scanner de QR code s’ouvre : ne le scanne pas. Touche le texte tout en bas : Connecter plutôt avec un numéro de téléphone.

5Saisis ton code

Entre les 8 caractères du code affiché sur LEYBOTDY (au-dessus). Dès que c’est bon, ton bot est connecté ✔

Conseils

  • Écris ton numéro avec l’indicatif du pays, sans « + », sans espaces ni tirets (ex : 2250700000000).
  • Le code expire au bout de 4 minutes. S’il a expiré, recommence simplement depuis le début.
  • Utilise le bouton 📋 Copier le code, puis colle-le dans WhatsApp : tu évites les fautes de frappe.
  • Garde la page LEYBOTDY ouverte pendant toute l’opération, ne la ferme pas.
  • Ce code s’affiche sur le site, pas par SMS ni dans WhatsApp. Ne le partage à personne d’autre.
  • Si ça échoue : mets WhatsApp à jour, vérifie ta connexion internet, puis réessaie avec un nouveau code.
  • Pour déconnecter ton bot un jour : WhatsApp › Appareils connectés › touche l’appareil › Déconnecter.
